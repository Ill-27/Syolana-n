# Контакты Syolana

## Текущий публичный адрес

На сайте Syolana сейчас используется один официальный публичный адрес:

- `syolana@yandex.ru` — общие вопросы, партнёрство, поддержка, идеи, жалобы и авторско-правовые обращения.

Личные адреса владельца/команды не публикуются.

## Партнёрские сайты

Для каждого партнёра предусмотрены три стандартных публичных способа связи:

- Yandex-почта;
- VK;
- Avito.

Кнопка показывается только если партнёр указал соответствующий публичный адрес/ссылку. Пустые контакты не отображаются.

## Важно

Переадресация входящих писем на доменные адреса может использоваться как технический слой, но пользователю всегда должен быть показан только актуальный публичный контакт. Пароли, API-ключи, SMTP-ключи и личные почтовые адреса нельзя хранить в публичном GitHub-репозитории.
