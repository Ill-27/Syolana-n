# План автоматической оплаты Syolana в РФ

## Рекомендуемый технический поток

1. Пользователь выбирает уровень языка или подписку.
2. Syolana создаёт платёж через провайдера.
3. Пользователь переходит на защищённую страницу провайдера.
4. Карточные данные не проходят через Syolana.
5. Провайдер отправляет webhook после успешной оплаты.
6. Serverless-функция проверяет подпись webhook.
7. Доступ записывается как entitlement: продукт, пользователь, дата окончания.
8. При возврате или отмене entitlement обновляется.

## Что не выбирать до проверки

Провайдер платежей пока не фиксировать в коде. Нужно выбрать сервис, который на момент запуска:

- работает с продавцом в РФ;
- поддерживает ваш фактический юридический/налоговый статус;
- даёт API и webhook;
- позволяет продавать цифровые услуги/курсы;
- поддерживает нужный порядок чеков и возвратов;
- имеет понятные условия автоплатежей, если они нужны.

## Для языковых уровней

Покупку A1/A2/B1/B2 лучше делать как отдельные продукты с бессрочным или явно указанным сроком доступа.

Автоплатёж полезнее для ежемесячной подписки на сайт партнёра. Для разовой покупки уровня языка подписка обычно не нужна.

## Секреты

API-ключи и webhook secrets нельзя хранить в публичном GitHub. Их нужно хранить в Secrets выбранного serverless-провайдера.
