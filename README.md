# Syolana

Публичная web-версия Syolana.

Этот репозиторий используется как временный deployment-source для действующего сайта. Канонические исходники premium-компонентов, внутренняя архитектура, серверные части и рабочая документация хранятся отдельно и не документируются здесь.

## Public repository rules

- не добавлять пароли, access tokens, payment secrets или приватные ключи;
- не добавлять внутренние юридические/административные документы;
- не публиковать новые закрытые учебные материалы как исходники;
- не размещать source maps для premium runtime;
- публичный frontend не является источником истины для лицензий, платежей или секретов.

## Статус

До завершения production-миграции этот репозиторий продолжает обслуживать текущую публичную версию сайта. После выбора production hosting/asset gateway он должен остаться только как минимальная публичная оболочка либо быть заменён чистым deployment-репозиторием без старой открытой истории.
