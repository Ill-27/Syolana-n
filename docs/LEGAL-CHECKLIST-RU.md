# Юридический чек-лист Syolana перед платным запуском в РФ

## Обязательно определить до первой оплаты

- кто именно является Исполнителем по оферте;
- реквизиты и налоговый режим;
- платёжный провайдер и чеки;
- финальная оферта;
- политика обработки персональных данных;
- фактический российский backend Partner Studio;
- роли Syolana и партнёра по персональным данным;
- процесс жалоб и ручного отключения;
- правила использования бренда и лицензии.

## Контент партнёров

Оптимальная модель для снижения риска:

- партнёр сам владеет доменом, хостингом и репозиторием;
- партнёр сам является издателем своих постов;
- Syolana не утверждает, что предварительно проверяет законность каждого материала;
- автоматическая проверка по умолчанию техническая;
- есть правила платформы и право отключения;
- есть рабочий notice-and-takedown;
- после уведомления спорный сайт можно быстро отключить от Syolana Core;
- собственный контент партнёра при этом не переписывается Syolana.

## Персональные данные

Согласно ч. 5 ст. 18 152-ФЗ в редакции, действующей после изменений 2025 года, при сборе персональных данных граждан РФ через интернет запрещено выполнять перечисленные операции с использованием баз данных за пределами РФ, кроме законных исключений.

Источник: https://www.consultant.ru/document/cons_doc_LAW_61801/cbf4e15b7c330f9372e876cdf2bc928bad7950ef/

Практический вывод для архитектуры Syolana: аутентификацию Studio и первичную базу персональных данных проектировать в РФ.

## Что можно оставить бесплатным на старте

- GitHub Pages партнёрского сайта;
- публичный репозиторий контента;
- GitHub Actions для сборки и деплоя;
- автоматический импорт публичных постов VK в черновики, если используемый API и лимиты это позволяют;
- ручное включение и отключение партнёра через GitHub Actions Syolana.

Это не гарантирует нулевые расходы навсегда: production backend, домены, уведомления, платежи и большие объёмы трафика могут создавать расходы.

## Перед публикацией финальных документов

Проверить российским юристом:

1. правовой статус Исполнителя;
2. применимость законодательства о защите прав потребителей к конкретным заказам;
3. обработку персональных данных и уведомление Роскомнадзора;
4. формулировки об ограничении ответственности;
5. порядок возвратов;
6. правила для несовершеннолетних покупателей или партнёров, если они допускаются;
7. лицензионные условия Syolana;
8. рекламные и маркетинговые формулировки и цены.
