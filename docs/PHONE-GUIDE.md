# Syolana: что делать с телефона

## 1. Где находится обновление

Основной репозиторий обновления: `Ill-27/Syolana-n`. Публичный адрес GitHub Pages: https://ill-27.github.io/Syolana-n/ . Текущие изменения описаны в [обновлении 1 октября](UPDATE-OCTOBER-1.md). Самостоятельно переносить файлы из старых ZIP-архивов для этого обновления не нужно.

Для книг откройте «Книги», выберите «Воробей» или «Демон», нажмите «Звуки и музыка». Цвет меняется по мере чтения; музыка и атмосфера плавно переходят между сценами. Громкость регулируется рядом. Звук запускается только после вашего нажатия. При переходе между главами он сохраняется, при выходе из книги выключается. Включение песни из общего плеера выключает атмосферу книги.

Для своих постов откройте https://ill-27.github.io/Syolana-n/#/editor . Это редактор файла ленты: заполните пост, скачайте `feed.json` и замените этот файл в корне GitHub. Фото и видео сначала загрузите в `assets`, затем укажите путь. Даты внутри файла нужны для порядка публикаций, но посетителям не показываются.

## 2. Что осталось подключить владельцу

Для кабинетов нужен серверный хостинг с постоянным диском и HTTPS. Для пользователей из РФ сначала проверить требования к персональным данным и размещению. Купленный домен Cloudflare сохраняется; код остаётся в GitHub. После выбора хостинга настраивается автоматическое развёртывание из проверенной ветки.

Затем нужны реквизиты оператора, окончательные документы и подключённый платёжный магазин. Пароли, токены и секрет ЮKassa не присылайте в чат и не записывайте в GitHub. Эти значения вводятся только в защищённые настройки хостинга.

## 3. Как менять баннер

После установки проекта загрузите картинку в `assets/banner.jpg` и в файле `config.json` замените блок `media`:

```json
"media": {
  "type": "image",
  "src": "assets/banner.jpg",
  "poster": "",
  "alt": "Новая книга и творческая студия Syolana"
}
```

Для видео:

```json
"media": {
  "type": "video",
  "src": "assets/banner.mp4",
  "poster": "assets/banner-poster.jpg",
  "alt": "Творческое пространство Syolana"
}
```

Рекомендуется MP4 с H.264; видео запускается без звука и зациклено; если браузер запрещает автозапуск, доступны его элементы управления. Заголовок, описание и ссылки редактируются рядом в том же JSON. Встроенный в изображение текст не переводится автоматически. JSON требует двойных кавычек и не допускает комментарии или лишнюю запятую после последнего элемента.

Одна конфигурация используется на всех страницах внутри платформы. После обновления развёрнутого проекта новые настройки появятся при следующем открытии/обновлении страниц; это не мгновенная рассылка в давно открытые вкладки.

## 4. Как добавить песню

Загрузите аудио, например `assets/music/stars.mp3`. В `config.json` добавьте объект в массив `songs`, сохранив уже подключённые три песни. Пример объекта:

```json
"songs": [
  {
    "src": "assets/music/stars.mp3",
    "title": "Там, где звучат звёзды",
    "artist": "Syolana",
    "sourceTitle": "Книга «Там, где звучат звёзды»",
    "sourceUrl": "#/book/turgenev_sparrow/0"
  }
]
```

Для второй песни поставьте запятую после первого объекта и добавьте следующий. `sourceUrl` может вести на книгу, портфолио, сайт или другую творческую работу. Используйте только те аудио и переработки произведений, на которые есть необходимые права. Рекламная цель сама по себе не заменяет разрешение правообладателя.

## 5. Как добавить тему

Для новой палитры скопируйте любой небольшой файл из `themes`. Пример `violet.js`:

```js
export default {
  id: 'violet',
  renderer: 'stars',
  accent: '#d7b6ff',
  dim: '#d0cadf',
  surface: '15,12,28',
  radius: '24px',
  colors: ['#bb90ff', '#70c9ff', '#ffbbdd']
};
```

Затем добавьте запись в массив `themes/manifest.json`:

```json
{
  "id": "violet",
  "name": "Фиолетовая ночь",
  "description": "Лиловый свет и воздушные звёзды",
  "module": "./violet.js",
  "preview": "linear-gradient(135deg,#1b2046,#573466)"
}
```

Для собственной анимации модуль темы может экспортировать `createRenderer(ctx)`, возвращающий `draw({delta,time,width,height})`, необязательные `resize(...)` и `dispose()`. Общий движок вызывает рисование и добавляет поверх водяные знаки. `particles: false` отключает стандартные звёзды. `backgrounds` — массив из трёх CSS-фонов для слоёв сияния; `buttonRadius` меняет кнопки. Такой модуль подключается только в реестре и работает на всех страницах; остальные файлы страниц редактировать не нужно. Общий рукописный шрифт заголовков Syolana Script хранится локально вместе с лицензией. Обычный текст и водяные знаки используют системный шрифт устройства. Набор шрифтов един для всех тем. Код тем добавляет только владелец платформы, не посетители.

## 6. Как автор добавляет книгу после установки сервера

1. Открывает «Моя студия», регистрируется.
2. Вводит название сайта, короткий адрес и описание.
3. Нажимает «Добавить», выбирает книгу, вставляет текст или загружает TXT.
4. Заголовки `Глава 1` или строки с `#` создают главы. Можно проверить разделение и назначить настроение каждой главе.
5. Добавляет обложку и, при необходимости, видео/аудио либо ссылку.
6. Сохраняет черновик или подтверждает права и отправляет материал на публикацию.
7. Вы рассматриваете его в «Модерации» под аккаунтом администратора.

При изменении опубликованного текста прежняя одобренная версия остаётся доступной до следующего одобрения. Редактор не умеет автоматически доказывать авторство или точно понимать эмоции художественного текста.

## 7. Как отменяется доступ

Сервер проверяет дату доступа; после её истечения страницы автора переходят к простому оформлению. Старые открытые страницы проверяются повторно раз в минуту. Загруженную посетителем копию нельзя удалённо стереть.

Автор может скачать JSON и ZIP независимого сайта. Экспорт включает его текущие черновики, поэтому перед размещением архива в открытом доступе нужно проверить, нет ли внутри неопубликованных материалов. Свои файлы автор сохраняет независимо от активности платного оформления.

Прекращение оплаты и блокировка по жалобе — разные ситуации. При блокировке страница недоступна; кабинет и выгрузка остаются. Возврат денег выполняется через платёжный кабинет отдельно.

## 8. Что можно делать сегодня

После установки показать новую версию 5–10 писателям и спросить: «Хотите загрузить свою книгу и попробовать такую страницу за 1 000 ₽ в месяц после бесплатной недели?» Это проверка интереса, а не продажа ещё не работающего сервиса.

Записать, кто готов принести текст, кому нужен собственный домен и кого не устраивает общий баннер. После серверной установки пройти с первыми авторами весь путь от регистрации до выгрузки. Подключать оплату после проверки этого пути и документов.
