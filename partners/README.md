# Partner entitlements

Демонстрационный центральный реестр доступа партнёров.

Если `active: true`, сайт партнёра получает центральный слой Syolana.
Если `active: false`, loader не загружает CSS, шрифты, темы, баннер, логотип, плеер и другие ресурсы Syolana.

Для коммерческого запуска этот публичный JSON будет заменён serverless endpoint с короткоживущими токенами и проверкой домена.
