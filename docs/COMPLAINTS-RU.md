# Syolana — порядок обращений и жалоб (РФ, рабочая версия)

## Цель

Быстро принимать обращения о правах, незаконном контенте, безопасности и нарушениях правил партнёрских сайтов, не превращая Syolana в редакцию, которая заранее утверждает каждую публикацию.

## Канал

Публичный контакт: **syolana@yandex.ru**.

На сайте Syolana также работает страница **#/report**. Если серверная форма недоступна, она формирует письмо на тот же адрес.

## Что желательно указать заявителю

- точную ссылку на страницу;
- краткое описание проблемы;
- какие права или нормы, по мнению заявителя, нарушены;
- контакт для ответа;
- для авторских/смежных прав — сведения, позволяющие подтвердить право или полномочия представителя.

## Процедура

1. Зафиксировать дату получения обращения.
2. Проверить, к какому партнёру и странице оно относится.
3. Если есть очевидный существенный риск — временно отключить Syolana Core для этого партнёра через ручной переключатель.
4. Передать обращение владельцу партнёрского сайта, если это допустимо и необходимо.
5. Не редактировать за партнёра спорный материал без отдельного основания; партнёр отвечает за свой контент и сам принимает решение по своей публикации.
6. При необходимости сохранить минимальный журнал действий: дата, ссылка, суть обращения, решение, дата ответа.
7. После разрешения ситуации можно вручную вернуть доступ к Syolana Core.

## Что не обещать

- что Syolana заранее проверяет законность каждой публикации;
- что отсутствие модерации полностью освобождает Syolana от любой ответственности;
- что Syolana гарантирует удаление контента с чужого домена после прекращения сотрудничества.

Syolana может отключить только собственный подключаемый слой и прекратить сотрудничество. Сам партнёрский сайт и его собственный контент остаются под контролем его владельца.
