# Ручное подключение и отключение партнёров

Syolana всегда сохраняет ручной переключатель доступа, независимо от будущей автоматизации оплаты.

## Где

GitHub → Actions → **Set partner access**.

## Как отключить

1. Запустить workflow вручную.
2. Указать `partner_id`.
3. Выбрать `inactive`.
4. Подтвердить запуск.

Workflow меняет только центральный `partners/entitlements.json`. После этого новый запрос партнёрского loader получает `active: false` и Syolana Core не загружается.

Видимо исчезают:

- логотип и баннер Syolana;
- темы и режим созерцания Syolana;
- плеер и музыкальная библиотека Syolana;
- фирменные шрифты и рекламные объекты Syolana;
- другие центральные компоненты.

Собственный домен, хостинг, посты, медиа и нейтральная оболочка партнёра остаются.

## Как вернуть доступ

Запустить тот же workflow и выбрать `active`.

## Важно

Центральное отключение гарантирует прекращение выдачи актуального подключаемого слоя Syolana с нашей стороны. Оно не может физически удалить строки или уже скопированные файлы из чужого репозитория, если владелец сайта отозвал у Syolana доступ и отказывается менять свой код.

Поэтому для обычного завершения сотрудничества предусмотрена отдельная автоматическая очистка партнёрского репозитория — **Detach optional platform layer**. Для коммерческой модели также нужны лицензионные условия, запрещающие использование Syolana после прекращения доступа.
