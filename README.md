# Syolana — единое творческое пространство

Обновление существующего проекта `Ill-27/Syolana`. Книги, MP3, буктрейлер и учебные материалы взяты из этого репозитория; оригинальные тексты и медиа сохранены.

## Статус

Актуальная публичная версия подготовлена для `Ill-27/Syolana-n`: см. [обновление 1 октября](docs/UPDATE-OCTOBER-1.md). Подключение домена к GitHub Pages не создаёт сервер аккаунтов, загрузок и платежей. Регистрация на внешнем домене и онлайн-оплата по умолчанию выключены. Не принимать оплату за ещё не запущенные кабинеты.

**GitHub Pages не предназначен для коммерческой SaaS-платформы.** Исходники могут остаться в GitHub; приложение, база и файлы авторов должны работать на подходящем серверном хостинге. Домен, купленный в Cloudflare, можно сохранить. [Ограничения GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).

## Что реализовано

- Общие темы для главной, библиотеки, читалки, уроков и сайтов авторов. Тема «Сияние звёзд» основана на предоставленном образце: северное сияние, разноцветные звёзды и движущиеся `syolana.com`. Ещё две темы: «Золотая волна», «Лунный сад».
- Случайная смена темы при обновлении, выбор вручную, пауза, reduced motion и остановка в фоновой вкладке. Новая тема может содержать собственный код рисования; водяные знаки добавляет общий движок.
- Шрифты из вашего образца размещены локально вместе с лицензиями OFL.
- Логотип слева, полный экран справа. Режим созерцания сохраняет доступ к управлению темами, музыкой и возврату интерфейса.
- Плеер с тремя существующими песнями: выбор, предыдущая/следующая, перемотка, громкость, перемешивание без повторов внутри круга, повтор одной/всех. Ссылки ведут к соответствующим текстам. Музыка продолжается при внутренней навигации.
- Каталог из `books/catalog.json`; «Воробей» с видеообложкой, обе части «Демона», существующая внешняя ссылка автора. Главы загружаются по мере открытия. Текст вставляется безопасно, без исполнения HTML.
- Читалка: оглавление, размер текста, сохранение места, спокойный фон, плавные читаемые цвета из исходной разметки. У новых книг — простая эвристика настроения с ручной настройкой; это не семантический ИИ. Звуковые сцены отложены.
- Пять существующих страниц A1 по испанскому/французскому встроены в общую оболочку. Их поиск, перевод и озвучка сохранены. Английский пока содержит вводный урок. Полнота уровней не подтверждена методической экспертизой.
- Четыре существующие страницы A2–B2 собраны отдельно от публичных файлов и выдаются сервером при активном доступе. **Эти тексты уже были в открытом репозитории и истории GitHub: такой перенос не делает опубликованные ранее копии секретными.** Новые закрытые материалы нельзя хранить в публичном GitHub.
- Сервер кабинетов: сессии, хеши паролей, CSRF, проверка происхождения запросов, разграничение авторов; редактор книг/публикаций, загрузка TXT и медиа, главы и черновики.
- Очередь модерации: сайт/изменения и публикации видны только после одобрения. Редактирование черновика не меняет уже опубликованную версию. Жалобы доступны администратору.
- 7 дней после первого одобрения. После истечения срока остаются опубликованные тексты и медиа в простом оформлении. Доступ проверяется сервером, открытая страница обновляет статус раз в минуту.
- Экспорт JSON и ZIP простого независимого HTML-сайта, доступный владельцу. Он включает и неопубликованные черновики: перед размещением экспорта проверьте состав.
- Адаптер ЮKassa: оплата месяца, проверка платежа через API, защита от повторного начисления и фиксация цены на год. Автосписания, автоматические возвраты и второй чек зачёта аванса не реализованы. Реальный магазин не подключён.

## Редактирование с телефона

Откройте [инструкцию владельца](docs/PHONE-GUIDE.md). Ежедневно нужны только GitHub и браузер кабинета после установки сервера.

| Что изменить | Где |
| --- | --- |
| Баннер, ссылки и песни | `config.json` |
| Новая тема | `themes/новая-тема.js` и `themes/manifest.json` |
| Каталог и собственные главы | `books/catalog.json`, `books/*.json` |
| Контент партнёров | «Моя студия» после подключения сервера |
| Публикации и жалобы | «Модерация» под администратором |

## Установка

[Развёртывание](docs/DEPLOYMENT.md) · [Правовые и коммерческие вопросы](docs/LAUNCH-AND-LEGAL.md).

Локальный запуск для разработчика:

```bash
python3 build.py
python3 platform/server.py
```

Открыть `http://127.0.0.1:8787`. Сборщик создаёт `dist/public` и `dist/private_lessons` отдельно. Сервер никогда не публикует папки аккаунтов, исходники Python и секреты как статику.

```bash
python3 -m unittest discover -s tests -v
node tests/test_player.mjs
node tests/test_catalog.mjs
```

GitHub Actions проверяет сборку, сервер, каталог, плеер, синтаксис и сборку Docker. Этот workflow сам не меняет DNS и не публикует сайт.

## Ограничения пилота

Один сервер, SQLite, 50 публикаций и 200 МБ медиа на автора, 20 МБ на файл; TXT UTF-8/вставка текста, до 500 глав и 2 млн символов на книгу. Нет импорта DOCX/EPUB, произвольного конструктора блоков, отдельных доменов авторов, автоматической почты/MFA и генерации ИИ. Страницы авторов имеют адрес `/#/s/имя`. Для большого каталога понадобятся другое хранение и фоновые очереди.

Ручная модерация означает, что новые материалы ждут администратора; существующие страницы работают без его присутствия. Полностью автоматическая работа и обязательное личное одобрение каждой публикации одновременно невозможны.

Оформление и музыка, переданные в браузер, могут быть скопированы. Истечение подписки отключает услуги платформы, но не стирает чужие сохранённые копии. Полная независимость от домена Syolana достигается размещением экспорта у другого провайдера.

Нет 100%-ной гарантии юридической защиты, продаж или сохранения всех клиентов. Ответственность зависит от применимого закона и фактической роли оператора, а не названия «провайдер шаблонов». Перед коммерческим запуском нужны действительные реквизиты и договоры, порядок жалоб, проверка обработки данных и платежей.
